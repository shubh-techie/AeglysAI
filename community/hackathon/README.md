# AeglysAI six-track technical hackathon

One offering, six beginner-friendly tracks. Use **any programming language**.
Select exactly one approved track. AeglysAI integration
is optional for the final challenge; a standalone local program is sufficient after mandatory qualification and selection. These are technical
challenge materials, not an announcement of event dates, prizes or judging staff.

- [Smart Login Guardian](tracks/smart-login-guardian.md)
- [Find the Anomaly](tracks/find-the-anomaly.md)
- [API Traffic Watch](tracks/api-traffic-watch.md)
- [Explain My Security Alert](tracks/explain-security-alert.md)
- [Predict the Outage](tracks/predict-the-outage.md)
- [Challenge 06: AI for Everyday Life](tracks/ai-for-everyday-life.md)

Start from the [project README template](templates/PROJECT-README.md),
[submission template](templates/SUBMISSION.md),
[reproducibility checklist](REPRODUCIBILITY.md) and [safety guide](SAFETY.md).
Example inputs are entirely synthetic and intentionally too small to establish
quality or independent impact. They do not include complete reference solutions.

Reviewers check the declared contract, minimum criteria, runnable tests and honest
limitations. No required hosted deployment, paid tool, production integration or
advanced ML library. The technical submission must run offline on declared prerequisites.

See [task status](STATUS.md) and [task roadmap](ROADMAP.md).

Read [mandatory qualification](QUALIFICATION.md), [judging](JUDGING.md) and [Workspace boundaries](WORKSPACE.md) before preparing a submission.

One AeglysAI AI/ML & Cybersecurity Hackathon; [teams](TEAMS.md) have 1–4 individually qualified and selected members, including the lead. Any programming language or framework is allowed for an executable MVP, proof of concept or working prototype after qualification.
