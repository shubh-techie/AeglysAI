# Event administration boundaries

| System | Responsibility | Visibility |
| --- | --- | --- |
| Google Forms | Registration, qualification evidence collection and final submission | Organizer-controlled responses |
| Private Google Sheets | Administration, eligibility, selection and judging | Authorized organizers and assigned judges |
| Private Google Drive | Supporting records, consent and review evidence | Least-privilege private access |
| GitHub | Forks, sanitized qualification evidence and project source code | Owner-reviewed public technical materials |
| AeglysAI-Portal | Approved public metrics, finalists and showcases | Approved public outputs only |

No application database is required. No Workspace integration or Portal code is implemented by these documentation contracts. Official Form URLs, access roles, retention, consent, withdrawal and publication owners require organizer configuration before operation. Do not enable public response summaries or link-share private Sheets/Drive records. Never publish private participant data, judging scores or confidential patent material. Release aggregates only after privacy and publication review; suppress small cells or identifying combinations when necessary.


Google Meet hosts finalist live demos and technical Q&A. No custom application database or authentication service is required. Private Sheets also maintain eligibility, team IDs, registration mappings and reviewed roster changes. Forms accept accessible evidence/video URLs; uploads are not mandatory. Publication consent is separate from judging consent; keep consent evidence and withdrawal handling private. Portal consumes only approved public event information and results, never private scores or participant mappings.
