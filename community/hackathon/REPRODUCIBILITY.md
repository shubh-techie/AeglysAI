# Technical reproducibility checklist

- [ ] Exact source commit and license are public-approved
- [ ] Language/runtime/platform and dependency versions declared
- [ ] Clean offline setup/run/test commands work
- [ ] Inputs are synthetic; no account, token or personal-data prerequisites
- [ ] Random seeds and repeated-run behavior documented where applicable
- [ ] Training/preprocessing separated from test data; no label leakage
- [ ] Output contract and example output included by the participant
- [ ] Normal, edge and malformed-input tests pass
- [ ] Observed results reported with limitations; no fabricated effectiveness
- [ ] Recommendations distinguished from actual mock controls
- [ ] Diff, dependencies and publication safety reviewed
